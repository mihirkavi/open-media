# ADR 0003: Transparent feed baseline

- Status: accepted
- Date: 2026-08-15

## Decision

Ship two built-in lenses: Raw, which is reverse chronological, and Relevant, which may use only recency, explicit follows, selected interests, and community membership. Explanations list both used and prohibited signals.

## Consequences

The initial ranking is deliberately simple and inspectable. Private messages, exact location, sensitive-trait inference, KYC material, and emotional-state prediction are outside the recommender boundary.
