# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue or pull request.

Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it and what an attacker could do with it.

You will get an acknowledgement as soon as possible. Please give us reasonable time to fix the problem before you disclose it publicly.

## Scope

In scope: the app in this repository, the Open Media Worker (public API, mail sync and events), the database rules in `supabase/`, and the bridge and gateway services in `services/`.

Out of scope: the third-party networks Open Media connects to (report those to the network itself) and attacks that need a compromised device.
